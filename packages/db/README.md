# `@coin-archive/db` schema

The tables below document the PostgreSQL schema in
[`src/schema`](src/schema). Column names match those in the database. In the Rules
column, **Required** means `NOT NULL`, and **Optional** means the column accepts
`NULL`.

All tables except `coin_surface_engravers` use a database-generated UUID `id`
as their primary key. All tables except `coin_ruling_authorities` have required
`created_at` and `updated_at` timestamps with time zones. Both default to the
insertion time; `updated_at` does not change automatically on update.

## `issuers`

| Column       | Type           | Rules                                                                                                         |
| ------------ | -------------- | ------------------------------------------------------------------------------------------------------------- |
| `id`         | UUID           | Primary key; generated by default.                                                                            |
| `name`       | `varchar(200)` | Required; nonempty, with no surrounding whitespace.                                                           |
| `code`       | `varchar(12)`  | Required and unique; either two uppercase ASCII letters or 3–12 uppercase ASCII letters, digits, and hyphens. |
| `created_at` | `timestamptz`  | Required; defaults to now.                                                                                    |
| `updated_at` | `timestamptz`  | Required; defaults to now.                                                                                    |

## `currencies`

| Column         | Type           | Rules                                                                                        |
| -------------- | -------------- | -------------------------------------------------------------------------------------------- |
| `id`           | UUID           | Primary key; generated by default.                                                           |
| `slug`         | `varchar(64)`  | Required and unique; 3–64 lowercase ASCII letters, digits, or single hyphens between groups. |
| `name`         | `varchar(200)` | Required; nonempty, with no surrounding whitespace.                                          |
| `period_label` | `varchar(200)` | Required; nonempty, with no surrounding whitespace.                                          |
| `created_at`   | `timestamptz`  | Required; defaults to now.                                                                   |
| `updated_at`   | `timestamptz`  | Required; defaults to now.                                                                   |

The Currency Full Name is derived from `name` and `period_label`; it is not
stored.

## `denominations`

| Column        | Type           | Rules                                                                                        |
| ------------- | -------------- | -------------------------------------------------------------------------------------------- |
| `id`          | UUID           | Primary key; generated by default.                                                           |
| `currency_id` | UUID           | Required reference to `currencies.id`; deletion of a referenced Currency is restricted.      |
| `label`       | `varchar(200)` | Required; nonempty, with no surrounding whitespace. Unique within a Currency, ignoring case. |
| `amount`      | `numeric`      | Required; greater than zero, less than 10¹⁸, and at most 12 fractional digits.               |
| `created_at`  | `timestamptz`  | Required; defaults to now.                                                                   |
| `updated_at`  | `timestamptz`  | Required; defaults to now.                                                                   |

## `ruling_authorities`

| Column       | Type           | Rules                                                                                        |
| ------------ | -------------- | -------------------------------------------------------------------------------------------- |
| `id`         | UUID           | Primary key; generated by default.                                                           |
| `slug`       | `varchar(64)`  | Required and unique; 3–64 lowercase ASCII letters, digits, or single hyphens between groups. |
| `name`       | `varchar(200)` | Required; nonempty, with no surrounding whitespace.                                          |
| `created_at` | `timestamptz`  | Required; defaults to now.                                                                   |
| `updated_at` | `timestamptz`  | Required; defaults to now.                                                                   |

## `engravers`

| Column       | Type           | Rules                                                                                        |
| ------------ | -------------- | -------------------------------------------------------------------------------------------- |
| `id`         | UUID           | Primary key; generated by default.                                                           |
| `slug`       | `varchar(64)`  | Required and unique; 3–64 lowercase ASCII letters, digits, or single hyphens between groups. |
| `full_name`  | `varchar(200)` | Required; nonempty, with no surrounding whitespace.                                          |
| `created_at` | `timestamptz`  | Required; defaults to now.                                                                   |
| `updated_at` | `timestamptz`  | Required; defaults to now.                                                                   |

## `coins`

| Column             | Type                | Rules                                                                                          |
| ------------------ | ------------------- | ---------------------------------------------------------------------------------------------- |
| `id`               | UUID                | Primary key; generated by default.                                                             |
| `title`            | `varchar(200)`      | Required; nonempty, with no surrounding whitespace.                                            |
| `issuer_id`        | UUID                | Required reference to `issuers.id`; deletion of a referenced Issuer is restricted.             |
| `denomination_id`  | UUID                | Optional reference to `denominations.id`; deletion of a referenced Denomination is restricted. |
| `distribution`     | `coin_distribution` | Required; `standard-circulation`, `circulating-commemorative`, or `non-circulating`.           |
| `first_issue_year` | `integer`           | Required; nonzero BCE/CE year.                                                                 |
| `last_issue_year`  | `integer`           | Required; nonzero BCE/CE year, greater than or equal to `first_issue_year`.                    |
| `created_at`       | `timestamptz`       | Required; defaults to now.                                                                     |
| `updated_at`       | `timestamptz`       | Required; defaults to now.                                                                     |

Indexes support list ordering and filtering by Issuer and Distribution.

## `coin_ruling_authorities`

Each row is one ordered Ruling Authority attribution for a Coin.

| Column                | Type           | Rules                                                                                                   |
| --------------------- | -------------- | ------------------------------------------------------------------------------------------------------- |
| `id`                  | UUID           | Primary key; generated by default.                                                                      |
| `coin_id`             | UUID           | Required reference to `coins.id`; deleted with its Coin.                                                |
| `ruling_authority_id` | UUID           | Required reference to `ruling_authorities.id`; deletion of a referenced Ruling Authority is restricted. |
| `role`                | `varchar(100)` | Required; nonempty, with no surrounding whitespace.                                                     |
| `tenure`              | `varchar(200)` | Optional; if present, nonempty and without surrounding whitespace.                                      |
| `position`            | `integer`      | Required and positive; unique within a Coin.                                                            |

The combination of `coin_id`, `ruling_authority_id`, `role`, and `tenure` is
unique, including when `tenure` is `NULL`. An index supports filtering by
Ruling Authority.

## `coin_surfaces`

| Column        | Type                | Rules                                                                                                                                                  |
| ------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`          | UUID                | Primary key; generated by default.                                                                                                                     |
| `coin_id`     | UUID                | Required reference to `coins.id`; deleted with its Coin.                                                                                               |
| `kind`        | `coin_surface_kind` | Required; `obverse`, `reverse`, or `edge`. Unique per Coin.                                                                                            |
| `description` | `text`              | Optional; if present, 1–10,000 characters with no surrounding whitespace.                                                                              |
| `image_key`   | `text`              | Optional; if present, 1–1,024 bytes with no surrounding whitespace. Cannot start with `/`, contain a URI scheme, or contain `.` or `..` path segments. |
| `created_at`  | `timestamptz`       | Required; defaults to now.                                                                                                                             |
| `updated_at`  | `timestamptz`       | Required; defaults to now.                                                                                                                             |

`image_key` stores an R2 object key, not a URL. The database allows both
`description` and `image_key` to be `NULL`.

## `coin_surface_engravers`

Each row credits one Engraver on a Coin Surface.

| Column            | Type          | Rules                                                                                                                     |
| ----------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `coin_surface_id` | UUID          | Required reference to `coin_surfaces.id`; deleted with its Surface. Part of the composite primary key.                    |
| `engraver_id`     | UUID          | Required reference to `engravers.id`; deletion of a referenced Engraver is restricted. Part of the composite primary key. |
| `position`        | `integer`     | Required and positive; unique within a Surface.                                                                           |
| `created_at`      | `timestamptz` | Required; defaults to now.                                                                                                |
| `updated_at`      | `timestamptz` | Required; defaults to now.                                                                                                |

The database does not restrict these credits to Obverse and Reverse; it also
allows Edge credits.
