# Coin Technique seed evidence for issue 94

Milled classifies a Coin type as machine struck. It does not describe the edge.

| Seed Coin                                                                   | Evidence for machine striking                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Finland, 2004, “Enlargement of the European Union by Ten New Member States” | The [European Commission's coin notice](https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=CELEX%3AC2004%2F243%2F03) identifies this issue as a 2 euro commemorative circulation coin. The [Bank of Finland's 2005 release](https://publications.bof.fi/bitstream/handle/10024/54093/Suomenpankki-fi-en_Releases_2005.pdf?sequence=1) says Finnish 2 euro commemorative coins are struck and identifies the 2004 enlargement coin as the preceding commemorative issue. Together these support the machine struck classification; the release does not separately describe the 2004 press. |
| Greece, 2004, “Olympic Games in Athens 2004”                                | The [ECB's 2004 catalogue](https://www.ecb.europa.eu/euro/coins/comm/html/comm_2004.ga.html) identifies this 2 euro issue. The [Bank of Greece's production description](https://www.bankofgreece.gr/en/the-euro/the-national-mint/production-of-coins) says all euro denominations are struck using minting presses.                                                                                                                                                                                                                                                                            |

All other seed Coins remain unknown until their own manufacturing method is verified.
